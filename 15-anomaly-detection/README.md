# 15 Anomaly detection

Rare events. Classical detectors first, then a fraud-style case where a flattering curve can still miss the class that matters.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-classical-detectors` | Isolation forest, one-class SVM, and a statistical threshold |
| `02-fraud-detection` | Extreme imbalance, an autoencoder, and a metric that does not hide the rare class |
