# 10 NLP

Classical text models against a small transformer, named entities, semantic search, and topics you can check by reading.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-classical-vs-transformer` | TF-IDF plus a linear model versus a small transformer, including cost |
| `02-named-entity-recognition` | Token-level labels on a public corpus, with a small subset if needed |
| `03-semantic-search` | Sentence embeddings and retrieval metrics, not only a nearest-neighbor demo |
| `04-topic-modeling` | Topics on a corpus short enough to read, checked against the documents |
