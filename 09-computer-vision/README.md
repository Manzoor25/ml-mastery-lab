# 09 Computer vision

Classification, transfer learning, detection, segmentation, and Grad-CAM. Small public images. A free GPU note only if a CPU run cannot finish.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-cnn-classifier` | A small convolutional net against a linear baseline on pixels |
| `02-transfer-learning` | A pretrained backbone and an augmentation ablation |
| `03-object-detection` | A pretrained detector on a small image set, with a CPU limit written down |
| `04-segmentation` | A small segmentation demo against a trivial mask baseline |
| `05-grad-cam` | Where a classifier is looking, including a case that highlights the wrong region |
