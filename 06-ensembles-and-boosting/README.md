# 06 Ensembles and boosting

Forests, a boosting loop you can read, the three common libraries on one table, and a stack that is allowed to lose.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-random-forests` | Why averaging trees helps, and where a single deep tree still fails |
| `02-gradient-boosting-from-scratch` | A small boosting loop written out, so the library is not a black box |
| `03-boosting-libraries` | The same tabular problem, three libraries, score and fit time |
| `04-stacking-blending` | Out-of-fold stacking, and a stack that may lose to the best single model |
