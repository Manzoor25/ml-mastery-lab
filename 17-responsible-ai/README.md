# 17 Responsible AI

Fairness, explanations, privacy on synthetic data, and a model card for a model this repo trained.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-fairness` | Group metrics and a mitigation attempt, including a gap that remains |
| `02-explainability` | SHAP, LIME, partial dependence, and a case where the explanation misleads |
| `03-privacy` | Differential privacy intuition and a PII pass on synthetic data |
| `04-model-cards` | A model card for a model this repo actually trained |
