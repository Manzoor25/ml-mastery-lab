# 04 Unsupervised learning

Clustering and dimensionality reduction, including the plots that look decisive and are not.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-clustering` | k-means, hierarchical clustering, DBSCAN, Gaussian mixtures, a segmentation case |
| `02-dimensionality-reduction` | PCA from scratch, t-SNE, UMAP, and the plots that mislead |
