# 13 Reinforcement learning

Bandits against a fixed test, then Q-learning, DQN, and a policy gradient on small environments.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-multi-armed-bandits` | Explore-exploit policies compared with a fixed A/B test |
| `02-q-learning` | A tabular agent on a small grid or FrozenLake, against a random policy |
| `03-dqn` | DQN on a small Gymnasium environment such as CartPole |
| `04-policy-gradient` | A simple policy gradient on a small environment, compared with the value-based run |
