# 08 Deep learning basics

Backprop in NumPy, the same idea in PyTorch, then the ways a training run fails. CPU-sized on purpose.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-nn-from-scratch` | A NumPy network with backprop, then the same model in PyTorch |
| `02-training-dynamics` | Initialization, batch norm, dropout, learning-rate schedules, overfitting |
| `03-debugging-training` | Overfit-one-batch, gradient checks, and how to read a loss curve |
