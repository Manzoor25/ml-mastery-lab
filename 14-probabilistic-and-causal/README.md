# 14 Probabilistic and causal ML

Bayesian tests, confounding, propensity scores, uplift, and difference-in-differences. The naive comparison stays in the table.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-bayesian-ab-test` | A posterior over a conversion rate, compared with a classical test |
| `02-confounding-propensity` | A naive comparison, then propensity score matching |
| `03-uplift-modeling` | Who responds because of the treatment, not who would buy anyway |
| `04-difference-in-differences` | A before-after comparison with a control group, and the parallel-trends assumption |
