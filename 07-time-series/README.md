# 07 Time series

Classical forecasts, lag features with a real backtest, a small neural model compared honestly, and a demand decision.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-classical-forecasting` | Decomposition, ARIMA or SARIMA, exponential smoothing, a naive baseline |
| `02-ml-forecasting` | Gradient boosting with lag and rolling features, scored with a backtest |
| `03-lstm-vs-baselines` | A small LSTM or temporal model against the classical and boosting baselines |
| `04-demand-forecasting` | From a forecast error to an inventory-style decision |
