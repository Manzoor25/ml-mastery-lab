# 11 LLMs and generative models

Tokenizers, a tiny transformer, retrieval-augmented generation, LoRA, evaluation, prompts, and a small generative model. Measured, not a screenshot.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-tokenization` | Vocabulary, merges, and how tokenization changes sequence length |
| `02-tiny-transformer` | A small transformer trained on a small corpus, against a simpler next-token baseline |
| `03-rag-pipeline` | Retrieval metrics plus a check on the answer, not a demo screenshot |
| `04-lora-finetune` | A small open model on a tiny set, or a documented Colab run if CPU cannot finish |
| `05-llm-evaluation` | An eval set you can read, and a concrete LLM-as-judge failure |
| `06-prompt-engineering` | Prompt variants with a measured outcome, not a vibe |
| `07-generative-models` | Small generative models on simple images, with a boring baseline |
