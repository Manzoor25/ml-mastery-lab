# 03 Classical supervised learning

The standard algorithms, each on a public problem, each with a baseline. The point is when the method works, not a tour of class names.

Nothing in this section has been run. Folders are created when the work starts.
Status lives in [PROGRESS.md](../PROGRESS.md). Run a project with `python main.py`
once its folder exists. Raw data is downloaded by the script and is not committed.

| Project | What it covers |
| --- | --- |
| `01-knn` | Distance-based classification, the curse of dimensionality, a simple baseline |
| `02-naive-bayes` | A probabilistic spam filter and the independence assumption |
| `03-svm-kernels` | Margins, kernels, and a plot of a boundary that is not a straight line |
| `04-decision-trees` | Splits, depth, and a tree a reviewer can read |
| `05-regularized-regression` | Correlated features, shrinkage, and what each penalty keeps |
